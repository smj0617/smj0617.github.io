codeilji-shorts 개인정보처리방침

시행일: 2026-11-04

어떤 도구인가

codeilji-shorts는 코드일지 유튜브 채널 운영자가 자기 PC에서 쓰는 개인용 도구입니다. 운영자가 만든 영상을 운영자 본인의 유튜브 채널에 올리기 위해 YouTube API 서비스를 사용합니다.

사용하는 Google 데이터

운영자가 Google 계정으로 허용한 범위 안에서만 다음을 사용합니다.

  • 영상 업로드와 썸네일 지정(youtube.upload)
  • 올린 영상의 공개 여부와 공개 예약 시각 바꾸기(youtube.force-ssl)
  • 올린 영상의 처리 상태 조회(youtube.readonly)

다른 사용자의 계정, 채널, 영상, 개인정보에는 접근하지 않습니다.

저장과 공유

  • 로그인 토큰은 운영자 PC에만 저장되며, 어떤 서버로도 보내지 않습니다.
  • 올린 영상의 id와 주소는 운영자 PC의 작업 기록에만 남습니다.
  • 수집한 정보를 제3자에게 팔거나 공유하지 않으며, 광고에 쓰지 않습니다.

권한 취소

언제든 Google 계정의 서드파티 앱 권한에서 이 도구의 접근 권한을 취소할 수 있습니다. 취소하면 PC에 저장된 토큰은 더 이상 쓸 수 없습니다.

관련 약관

이 도구는 YouTube API 서비스를 사용합니다. 사용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
